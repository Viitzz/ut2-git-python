\# Cómo contribuir a este proyecto 

&#x20;

\## Flujo de ramas 

Nunca se trabaja directamente sobre `main`. Para cada cambio se crea una 

rama nueva a partir de `main` (`git switch -c nombre-descriptivo`). 

&#x20;

\## Instrucciones para mensajes de commit 

En este caso se sigue el formato de `tipo: descripción`, con los tipos `feat`, `fix` como suele ser habitual. 

también se usan `docs`, `style`, `refactor`, `test` y `chore`

&#x20;

\##  Instrucciones de cómo proponer un cambio 

1\. Crea una rama desde `main`. 

2\. Haz tus commits en ella. 

3\. Sube la rama: `git push -u origin nombre-de-la-rama`. 

4\. Abre una Pull Request en GitHub describiendo el cambio. 

5\. Espera la revisión antes de fusionar. 

&#x20;
